プライバシーポリシー

tenchan-reader は開発者本人だけが使う個人用の道具です。

読むもの

  • Gmail・Google カレンダー・Google ドライブを読み取り専用の範囲（gmail.readonly・calendar.readonly・drive.readonly）だけで読みます。書き込み・送信・削除の権限は求めません。
  • どのアカウントかを知るために、メールアドレス（openid・email）を読みます。

使い方と保存

  • 読んだ内容は、開発者本人の予定やメールの確認を手伝うためだけに、本人のコンピューターの中で使います。本人が使う AI アシスタントが本人のために読むことがあります。
  • 他の人への共有・販売・広告への利用はしません。読んだ内容を外部の保存先へ書き出しません。
  • 認可の鍵は本人のコンピューターの OS の鍵の保管庫にだけ置きます。
  • Google API から受け取った情報の使い方は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

取り消し

許可はいつでも Google アカウントのサードパーティのアクセス から取り消せます。

tenchan-reader is a personal tool used only by its developer. It requests read-only scopes (gmail.readonly, calendar.readonly, drive.readonly) plus openid/email. Data is used only on the developer's own computer to help the developer, is never sold, shared with others or used for advertising, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
